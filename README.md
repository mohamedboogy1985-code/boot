# ChatterBots Remix — وكيل الذكاء الاصطناعي المحاسبي (مدمج مع Bogy-Agants/NexusAI)

منصة وكلاء صوتيين متعددة الشخصيات موجّهة للمحاسبة، تجمع بين:

- **6 وكلاء محاسبين بصوت وكاميرا** (Gemini + TTS + Web Speech) وتسجيل جلسات محلي (IndexedDB).
- **تحليل مالي للنصوص بالمعايير المصرية**: استخراج المصروفات/الإيرادات وخصومات ضريبة القيمة المضافة **14%** (قانون 67/2016)، والفاتورة الإلكترونية لدى **مصلحة الضرائب المصرية (ETA)**، ونظام الخصم والتحصيل تحت حساب الضريبة — مع خيار الريال (15%/ZATCA).
- **عملات متعددة: الجنيه المصري (افتراضي) + الدولار الأمريكي + الريال السعودي** (مبدّل عملة في جناح المحاسبة، محفوظ محليًا).
- **تصدير حقيقي**: Excel ‏(XLSX متعدد الأوراق)، Word ‏(DOCX)، ‏PDF (حفظ كـ PDF)، وCSV — من بطاقة التصدير في جناح المحاسبة ومن محلّل النصوص.
- **مخططات Recharts** لتوزيع المصاريف والإيرادات (جلسة محددة أو مجمّعة لكل الجلسات) داخل بطاقة تفاعلية في `AccountingSuiteView`.
- **حدّ ميزانية شهري (Budget Threshold)**: عند تجاوز مصروفات الشهر للحد الذي تختاره يصدر تنبيه صوتي + إشعار متصفح مرئي.
- **إشعارات متصفح (Notification API)** عند اكتمال التخطيط/المهام والتحليلات وإجراءات المحوّلات — حتى والتبويب في الخلفية (`src/services/notificationService.ts`).
- **المُنسّق متعدد الوكلاء**: هدف واحد يتحول لمهام مفوّضة لكل وكيل — تُدخل الهدف من **صندوق نصي أو بالإملاء الصوتي** في وحدة `VoiceController`، ويُعالج عبر `handleExecuteMultiAgentGoal`.
- **جسر Ollama محلي (offline-first)**: تشغيل أدوات محاسبية/تلخيص/ترجمة على نموذج محلي دون مغادرة البيانات جهازك؛ وبدون Ollama متاح يقول النظام ذلك صراحة (بدون ردود مزيفة).
- **تشخيص نظام حقيقي** عبر `systeminformation` (CPU/RAM/أقراص/عمليات).
- **محوّلات آمنة (Adapters)** للمتصفح والملفات والفأرة ولوحة المفاتيح — بنموذج «الإنسان في الحلقة» الموثق أسفله.
- **حارس أمني + سجل تدقيق** لكل إجراءات التحكم.

## التشغيل

```bash
npm install          # تثبيت نظيف — بدون أي أعلام إضافية
npm run dev          # تطوير: http://localhost:3000
npm run build        # بناء الإنتاج
npm start            # إنتاج (tsx server.ts)
npm run lint         # فحص TypeScript (0 أخطاء)
```

انسخ `.env.example` إلى `.env` واضبط:

| المتغير | الوصف |
|---|---|
| `GEMINI_API_KEY` | مفتاح Gemini للتحليل الحي والمحادثة. بدونه يعمل النظام بمحركات استدلالية محلية **موسومة صراحةً كمحاكاة** في الواجهة والملفات. |
| `OLLAMA_HOST` | عنوان Ollama المحلي (افتراضي `http://localhost:11434`). |
| `ENABLE_DESKTOP_ADAPTERS` | مفتاح التنفيذ الفعلي للفأرة/لوحة المفاتيح. افتراضيًا `false` = وضع المعاينة الآمن. |
| `PORT` | منفذ الخادم (افتراضي 3000). |

## نموذج أمان المحوّلات (Adapters) — مهم جدًا

صُمم النظام ليعطيك **كل القدرة** دون منح الـ LLM أي سلطة تنفيذ:

1. **النموذج يقترح فقط**: `/api/adapters/propose` يحوّل هدفك (نصًا أو صوتًا، وبمساعدة Ollama إن توفر) إلى إجراءات من **قائمة بيضاء صارمة** — تتم تصفية أي إجراء خطير تلقائيًا.
2. **أنت توافق على كل إجراء منفردًا**: التنفيذ يتطلب `approvedByUser: true` من نقرة موافقة + تأكيد. بدونها يستجيب الخادم بـ 403 ويُسجَّل الحدث.
3. **الفأرة/لوحة المفاتيح الحقيقيتان معطّلتان افتراضيًا (Dry-Run)**: لتفعيلهما على جهاز ويندوز الخاص بك فقط:
   ```bash
   npm i @nut-tree/nut-js          # حزمة اختيارية — ليست تبعية للمشروع
   # في .env:  ENABLE_DESKTOP_ADAPTERS=true
   ```
   وحتى عندها: تعملان فقط لطلبات نفس الجهاز (loopback)، والنص يمر على الحارس الأمني، والمفاتيح من قائمة بيضاء.
4. **محوّل المتصفح** = جلب HTTP محروس (يمنع SSRF للعناوين الخاصة/الداخلية) مع تهيئة User-Agent والمهلة من الواجهة. عرض JavaScript الكامل/لقطات الشاشة يتطلب تثبيت Playwright محليًا اختياريًا (`npm i playwright`) وهو غير مفعّل افتراضيًا.
5. **محوّل الملفات** = قراءة فقط داخل مجلد `./adapter-workspace` مع منع تجاوز المسار وأنواع ملفات نصية محدودة.
6. **لا يوجد تنفيذ أوامر نظام إطلاقًا**: الخادم لا يحتوي أي نقطة نهاية تنفيذ Shell (السكربتات تُولَّد كنص للمراجعة والنسخ اليدوي فقط) — وذلك عمدًا لحماية جهازك (في مشروع Bogy-Agants الأصلي كانت توجد نقطة تنفيذ بلا مصادقة تمثل ثغرة RCE؛ لم تُنقل هنا).

## بنية مختصرة

- `server.ts` — Express + واجهات Gemini/TTS، والحارس الأمني وسجل التدقيق، والمُنسّق، والتشخيص الحقيقي، وجسر Ollama، والمحوّلات.
- `src/components/` — الواجهات: `LiveVoiceChat`، `AccountingSuiteView` (عملات/تصدير/ميزانية/مخططات)، `FinancialTranscriptAnalyzer`، `DeepControlHub` (تبويبات التحكم + اللوحات المدمجة في `MergedControlPanels.tsx`)، `VoiceController` (إدخال صوت/نص).
- `src/services/` — `api`، `localDb` (IndexedDB)، `fileExportService` (XLSX/DOCX/CSV/PDF)، `currency` (EGP/USD/SAR)، `notificationService` (Notification API + تنبيه الميزانية)، `audio`/`soundEffects`.

## التوافق المحاسبي المصري

- ضريبة قيمة مضافة **14%** وخصم ضريبة مدخلات في الإقرار الشهري (نموذج 10).
- منظومة **الفاتورة الإلكترونية/الإيصال الإلكتروني** لدى مصلحة الضرائب المصرية (ETA) وقانون الإجراءات الضريبية الموحد 206/2020.
- **الخصم والتحصيل تحت حساب الضريبة** (نموذج 41) عند السداد للموردين.
- البيانات الاستدلالية (وضع المحاكاة) موسومة دائمًا ولا تصلح كسجلات رسمية.
